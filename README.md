# Shopping List and Cost Calculator

A beginner-friendly Java console project demonstrating arrays.

## Features
- Stores shopping item names in a `String[]` array.
- Stores item prices in a `double[]` array.
- Displays all items and their prices.
- Calculates the total shopping cost.
- Finds the most expensive item.
- Compares the total with the user's budget.
- Validates item count, prices, and budget input.

## Requirements
- Java 8 or later, or an online Java compiler.

## Run locally
1. Save the source code as `Main.java`.
2. Open a terminal in the folder containing the file.
3. Compile it with `javac Main.java`.
4. Run it with `java Main`.

You can also paste `Main.java` into an online Java compiler and click **Run**.

## How arrays are used
The program creates two arrays after the user enters the number of items: `String[] items` stores item names, and `double[] prices` stores corresponding prices. Both arrays use the same index to associate an item with its price. A loop displays the items and calculates the total.

## Example test
Try 3 items: Bread — 15, Milk — 22, Apples — 18. With a budget of 60, the total is 55 and the remaining budget is 5.
